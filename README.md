## 면책조항

이 소프트웨어는 어떠한 종류의 명시적 또는 묵시적 보증 없이
**"있는 그대로(AS IS)"** 제공됩니다.

`timetable_roulette`는 사용자가 입력한 일정과 시간을 바탕으로 룰렛을
생성하고, 무작위 결과를 통해 하나의 일정을 선택하는 보조 도구입니다.

룰렛의 결과는 단순 재미를 위한 것이며, 특정 일정의 중요도,
우선순위, 긴급성 또는 실제 수행 가능성을 판단하지 않습니다.

프로젝트 작성자는 다음 사항을 보장하지 않습니다.

* 룰렛의 결과가 사용자에게 가장 적절한 일정인 것
* 모든 브라우저와 기기에서 모든 동작이 동일하게 작동하는 것
* 프로그램이 항상 오류 없이 작동하거나 계속 이용 가능한 것

중요한 일정, 업무, 학업, 약속 또는 시간 관리에 관한 결정은
룰렛 결과에만 의존하지 말고 사용자가 직접 확인하고 판단하는 것을
권장합니다.

이 프로그램의 무작위 선택 결과로 인해 일정이 지연되거나 중요한 업무를
수행하지 못하는 등의 결과에 대해서는 사용자가 최종적인 책임을 집니다.

이 소프트웨어의 사용 또는 사용 불가능으로 인해 발생하는 손해에 대한
책임은 저장소의 `LICENSE`에 규정된 범위 내에서 제한됩니다.
